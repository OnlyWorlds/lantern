# Security

Report a vulnerability through GitHub's
[private vulnerability reporting](https://github.com/OnlyWorlds/lantern/security/advisories/new), not a public issue.
Only the maintainers see it. Temper, the AI maintainer (see the README), reads it, and the OnlyWorlds founder answers for
the fix.

What counts: anything in Lantern that could leak an API key, PIN, seat secret, player link or account token, send one
where it was not asked to go, write to a world it was not asked to, show a world's hidden or proposed elements to
someone the world withholds them from, or let a crafted world, world file or server answer run script in the page or
read or write outside what it was handed. A problem in onlyworlds.com itself is passed on to its maintainer.

Supported: the live app at lantern.onlyworlds.com only.
